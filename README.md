# Neo Todo (Vite + React)

Neo Todo is a polished, minimal React todo app built in this Vite repo. It persists state to localStorage and provides a clean, responsive UI for desktop and mobile.

How to use
- Install dependencies: `npm install`
- Start dev server: `npm run dev`
- Build for production: `npm run build`
- Preview production build: `npm run preview`

Features
- Add todos, toggle complete, delete, and clear completed
- Inline empty state when no todos exist
- Small stats: total, active, completed
- Persist todos in localStorage
- Accessible labels and keyboard-friendly controls (Enter to add; toggle with click or keyboard/select)
- Minimal dependencies (no UI libraries)
- Responsive UI with a clean, contemporary look

Notes
- This is a local, self-contained app. No remote repo is created by me.
